# Change Log

## 9.1.0

### SDK Updates
- Wraps Android SDK 9.4.0 API
- Wraps iOS SDK 9.4.0 API

### Bug Fixes
- Fixed support for fabric components

## 9.0.0

### Breaking Changes
- **Package renamed** from `ironsource-mediation` to `unity-levelplay-mediation`
- The old plugin `ironsource-mediation` is now **deprecated**
- Removal of old deprecated IronSource classes and methods

### New Features
- Add support for Fabric components
- Add support for Turbo Modules
- Add support for React Native New Architecture

### SDK Updates
- Wraps Android SDK 9.2.0 API
- Wraps iOS SDK 9.2.0 API

### Architecture Support
- Legacy architecture: React Native 0.68+
- New architecture: React Native 0.74+

## 3.2.0
